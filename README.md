# omi-desktop-releases

Windows installers and latest.yml update metadata for the Reece build of Omi,
published by .github/workflows/windows-release.yml in mrichard33/omi.

No source code lives here, and that separation is the point: the read-only
token baked into every installed copy is scoped to this repository alone.
See desktop/windows/docs/reece-release.md in mrichard33/omi.
